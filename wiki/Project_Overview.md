## Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/drshanali/portfolio.git
cd portfolio
```

### 2. Start Local Server
```bash
python -m http.server 8000
# Open http://localhost:8000
```

### 3. Make Changes
Edit HTML/CSS/JS files and refresh browser

### 4. Deploy
```bash
git push origin main
# Auto-deploys to live site
```

## Common Tasks

### Add a New Page
1. Create `pages/new-page.html`
2. Copy from similar page
3. Update content
4. Add navigation link
5. Test locally
6. Commit and push

### Update Content
1. Edit `.html` file
2. Refresh browser
3. Verify changes
4. Commit and push

### Add Images
1. Compress image
2. Place in `images/` folder
3. Add to HTML with alt text
4. Test locally
5. Commit and push
